# Customer_Behavior_Analysis
 Overview:

This project is an end-to-end **Data Analytics project** focused on analyzing customer shopping behavior and identifying meaningful patterns and business insights from customer purchase data.

The project covers data analysis using **Excel, SQL, Power BI**, along with a detailed report and presentation.

---

Project Files:

The project contains the following files:

- **Customer Behavior.xlsx** – Source dataset used for analysis
- **customer_behavior.sql** – SQL queries used for data analysis
- **customer_behavior_2.sql** – Additional SQL queries and analysis
- **Customer_Behavior_Dashboard.pbix** – Interactive Power BI dashboard
- **Dashboard.png** – Preview image of the Power BI dashboard
- **Customer Shopping Behavior Analysis.pdf** – Project report
- **Customer Shopping Behavior Analysis pptx** – Project presentation

---

Tools & Technologies:

- **Excel** – Dataset and initial data handling
- **SQL** – Data analysis and business queries
- **Power BI** – Interactive dashboard and visualization
- **Python** – Data analysis and exploratory analysis
- **Gamma** – Presentation creation

---

Project Workflow:

1. Data Collection & Preparation

The customer shopping behavior dataset was imported and examined to understand the available data and identify important customer and purchase-related attributes.

2. Data Cleaning & Analysis

The data was prepared for analysis by checking data quality, handling inconsistencies, and organizing the required fields.

Exploratory analysis was performed to identify:

- Customer purchasing patterns
- Product preferences
- Purchase behavior
- Customer demographics
- Spending patterns
- Discounts and purchasing trends

3. SQL Analysis

SQL queries were used to perform business-oriented analysis and extract meaningful insights from the dataset.

The analysis includes questions related to:

- Customer purchasing behavior
- Product/category performance
- Customer spending
- Purchase frequency
- Discounts
- Payment methods
- Customer segmentation

4. Power BI Dashboard

An interactive **Power BI dashboard** was created to visualize the key findings.

The dashboard provides insights into:

- Customer behavior
- Purchase trends
- Product categories
- Customer demographics
- Spending patterns
- Purchase frequency
- Other important KPIs

5. Report & Presentation

The findings from the analysis were documented in a detailed **project report** and summarized in a **presentation** for easy understanding of the key business insights.
